## What is this

Merkaba is two counter-rotating tetrahedra that create a **temporal gradient**:

- Upper: v = φ·c → Lorentz factor γ → ∞ → "outside time"
- Lower: v = (1/φ)·c → γ ≈ 1.272 → "in time"
- Cell is born **at the boundary between two times**

This is not a metaphor — it's a concrete physical model where:

- Time flows at different rates in the two tetrahedra
- The gap between them generates an entropy source
- Each Cell carries a relativistic γ factor from its birth moment
